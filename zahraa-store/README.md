## 🚀 كيفية الاستخدام والتشغيل

### الطريقة الأولى: التشغيل المباشر في المتصفح (Static / Client-side)
1. **عرض المتجر:** افتحي الملف `index.html` في أي متصفح.
2. **لوحة التحكم:** افتحي الملف `admin.html`، وسجّلي الدخول بـ `admin` / `zahra2026`.
3. لتغيير بياناتكِ، انتقلي إلى تبويب **"إعدادات الحساب والملف الشخصي"**، واكتبي اسم المستخدم الجديد وكلمة المرور الحالية والجديدة مع التأكيد واضغطي **"حفظ وتحديث بيانات الدخول"**.

### الطريقة الثانية: التشغيل عبر خادم Node.js (Fullstack Server)
```bash
npm install express
node server.js
```
ثم فتح المتصفح على:
- المتجر: `http://localhost:3000/index.html`
- لوحة التحكم: `http://localhost:3000/admin.html`

### الطريقة الثالثة: التشغيل على استضافة PHP / cPanel / Apache
- نقل المجلد إلى سيرفر الويب أو `htdocs` / `public_html`.
- تقوم الملفات في مجلد `api/` بحفظ التحديثات مباشرة في `config/admin_credentials.json` بتشفير `BCRYPT`.
